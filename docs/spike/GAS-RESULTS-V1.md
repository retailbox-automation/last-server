Generated by `spike/tests/sandbox.rs` (`bench_v1_gas`). Bots: survivor fights, drinks, rests, collects items and graves, opens the vault with a key, descends to depth 15; looter goes for graves first; rusher runs for the stairs (most new maps per move); avoider plays like survivor but walks around graves (it reads every grave on its depths and loots none). Every bot walks back up and returns to the surface before its moves run out (a log that ends inside the dungeon counts as a death). Before each row with graves the server is refilled to 10 graves on each of depths 1 to 10 by real dives that end on spots where graves never cut the day's map apart (`ls_core::bot::safe_grave_spots`, `moves_to_quit_at`): 99 dives for the first fill, 102 for the refills. Graves per depth before every row: `graves_summary_before_each_graves_row` in the JSON.

Threshold: 300 moves with 100 graves on depths 1 to 10 must cost at most 10 Tgas. Worst such run: 9.41 Tgas, PASS (4 qualifying 300-move runs; they entered depths holding at least 20 graves). Worst 300-move run before filling: 5.98 Tgas; worst 1000: 9.80 / 16.73 Tgas (before filling / depths 1-10 full); worst 3000: 17.20 / 23.47 Tgas.

## Reproduce

```sh
# toolchain: rustc with the wasm32-unknown-unknown target; .cargo/config.toml adds --cfg near for wasm
cargo test -p ls-core --features serde
cargo build --target wasm32-unknown-unknown --release -p ls-contract
cargo test -p spike --release --test sandbox bench_v1_gas -- --nocapture   # downloads near-sandbox on first build
```
