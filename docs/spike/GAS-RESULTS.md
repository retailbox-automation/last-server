survivor = fights, rests, collects, takes stairs down to depth 15; rusher = runs for the stairs every turn (most new maps per move; it dies early on long logs, see moves applied). Depth reached = maps generated, since every dive starts at depth 1.

Least-squares fit over all 24 runs: 2.088 Tgas fixed + 0.00253 Tgas per move + 0.2752 Tgas per new map. At 1000 Tgas that is about 255606 moves at the survivor pace (1 map per 200 moves) or 111501 at the rusher pace (1 map per ~43 moves), before other limits (4 MiB arguments, graves in state) matter.

Each grave in state adds about 0.171 Tgas to every dive (20-grave median vs no graves), so a 300-move dive reaches 100 Tgas at roughly 562 graves on the server: graves must be bucketed by depth and capped.

Threshold: 300 moves must cost at most 100 Tgas. Worst 300-move run without graves: 4.78 Tgas, PASS.

## Reproduce

```sh
# toolchain: rustc with the wasm32-unknown-unknown target; .cargo/config.toml adds --cfg near for wasm
cargo test -p ls-core --release
cargo build --target wasm32-unknown-unknown --release -p ls-contract
cargo test -p spike -- --test-threads=1 --nocapture   # downloads near-sandbox on first build
```
